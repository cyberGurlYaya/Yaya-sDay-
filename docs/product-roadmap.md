# Yaya'sDay — Product Roadmap

## V1 — Core companion
- Personalized onboarding
- Name + nickname generation
- Create-your-own nickname
- Personality selection
- Optional Muslim Mode
- My Day
- Natural-language task capture
- Voice input
- Smart scheduling
- Fixed vs flexible tasks
- Rest and buffers
- Adaptive rescheduling
- Notifications/reminders
- Talk to Yaya
- Progress reflection
- Free/Premium foundation

## V1.x — Reliability and device integration
- Better notifications
- Alarm integration where appropriate
- Improved scheduling edge cases
- Android-specific device capabilities
- Performance/accessibility/privacy hardening

## V2
- Focus Mode
- Deeper personalization
- More advanced planning intelligence

## V2.5 / V3
- Hey Yaya background assistant
- Two-way spoken conversation
- Yaya speaks back
- Kids Mode
- Parent ↔ child linking
- Parent-created child tasks/reminders
- Parent monitoring and controls
- Optional accountability/proof features
- Expanded Ramadan capabilities

## Design principle
The current Figma work is a prototype, not the final design. Final visual polish and additional interaction states should be updated after the working product exposes real interaction requirements.
