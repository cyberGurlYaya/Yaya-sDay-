# Scheduling engine

This directory contains application-owned scheduling rules. AI can interpret natural language and propose structured task metadata, but scheduling decisions must pass through deterministic rules before they affect a user's day.

Initial principles:
- protect fixed commitments;
- protect rest, meals, and other self-care;
- respect deadlines and priority;
- avoid over-scheduling;
- preserve breathing room and buffers;
- reschedule flexible tasks when the day changes;
- never shame the user for falling behind.
